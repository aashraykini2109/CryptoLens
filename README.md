# CryptoLens Dashboard

Post-Quantum Cryptographic Migration Auditor & Interactive Cyber Dashboard. Featuring a fluid-simulation background, real-time NIST compliance analysis, and premium dark-mode cybersecurity visual scaffolding.

## Getting Started

Follow these simple steps to clone, install, and run the dashboard locally.

### 📋 Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v18 or higher recommended) installed.

### 🚀 Setup & Run

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   cd dev_jams_ui
   ```

2. **Install dependencies:**
   *(Note: `node_modules` is excluded from Git version control, so this step downloads the required packages listed in `package.json`)*
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Go to `http://localhost:5173` to view the live dashboard.
